# 0.2.4 已知限制與驗證邊界

使用者已回報疾病分類人員測試內容正確、功能可初步使用，並要求發布0.2.4。App名稱自0.2.3移除Demo；以下仍未完成或有範圍限制的項目，不因此標為通過。

## 平台與成品

- Windows0.2.4已在GitHub hosted Windows runner完成原生測試、完整CRT封裝與EXE啟動／獨立user.sqlite檢查；**不等同乾淨Windows工作站與人工操作驗收**。
- Android0.2.4已用獨立`.debug`套件在ARM64實機驗證同一FY2025原包、九組完整查詢及載入更多。這不是所有裝置與正式Release APK覆蓋安裝的完整驗收。
- 實體平板、旋轉／狀態保留、TalkBack與Windows螢幕閱讀器未完整實測；390／800／1440寬及1.6倍文字widget測試不取代實體裝置。
- APK沿用前版開發簽章，便於目前使用者覆蓋升級；未配置商店發行金鑰，不宣稱Play商店簽署。此次發布不改簽章或清除使用者資料。

## 搜尋與資料內容

- 449節點範例核對的是階層深度／目標碼位置，不是取得smarticd10未公開的PHP後端。網站可能重整Note或忽略單字元數字；App保留官方原文、父子關係與type1／2區分，不保證所有查詢完全一致。
- 索引導引支援每100筆分頁與完整總數；**舊全文相關度模式仍限制前100筆**，不是所有搜尋模式都改為完整分頁。
- 官方拆分／合併lineage尚未完成；版本差異只比較已實作的新增／移除／描述／狀態／notes，不保證同碼跨版語義等價。
- NHI2014／2023同版中英包只對自身版本有效，不自動當成美國FY2023／FY2027中譯。unresolved附加中譯保持未確認狀態，不進入合格中文搜尋。
- NHI原檔沒有的美國Chapter／Block、Index、Tabular notes或PCS七軸不補造；碼前綴只是導覽。2014原檔未提供USE時明示未知狀態，不從leaf或保守儲存的billable=0推定申報資格。
- 完整官方資料與使用者資料不隨Release散布。工具samples與負向fixtures均為測試用途；不能當成正式分類內容。

## 安全、效能與資料保存

- 既有ZIP／XML／SQLite安全驗證與交易錯誤注入測試保留；所有資料版本的飛航／封鎖網路、真實磁碟滿、強制中斷／重啟仍未全量實測。
- FY2025原包在Linux與Android有完整查詢快照比對；Windows此次跨端快照使用合成資料。不能宣稱所有年度在所有平台均已全量驗證。
- Linux暖查詢首頁p95為8.041ms（100次）；不是UI繪製時間、冷啟動、各裝置1000次或正式中文效能Gate的完整報告。
- ZIP上限256MiB、總解壓512MiB、最多三檔、metadata各1MiB、比例200、JSON深度64、分類深度100；大包不能靠停用檢查繞過契約。
- SHA256是完整性檢查，不是官方數位簽章。來源機關、版別及原檔仍須核對；profile鎖定特定批次，官方新批次需另行驗證。
- 收藏／個人註解按資料包版本隔離，不自動遷移到另一版本；僅本機儲存，無雲端同步。Android卸載／清資料可能移除資料，Windows需保留整份portable-data。

歷史限制以各版實測報告為準；目前操作方式以[使用指南](USER_GUIDE.md)為準。
